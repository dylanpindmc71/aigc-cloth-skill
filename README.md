# aigc-cloth-skill

把照片中的服装提取成白底三视图参考板。支持单张照片、多张参考图和照片文件夹，**每套服装一张成品，可批量处理并指定输出目录**。

这是供 AI Agent 执行的 Skill，不是独立生图软件。它通过运行环境提供的内置 `image_gen` 工具生成图片。

## 成品规格

- **4:3 横版、白色背景，无人物、人体或可见人台。**
- 左侧 2/3：正面、侧面、背面，比例、穿法、颜色统一。
- 右侧 1/3：四张服饰细节卡，展示纹理、接缝、扣件、鞋子或配饰。
- 尽量保留参考照片中的款式、材质与细节；衣鞋完整不裁切。
- 每套只交付一张最终图，并附任务清单 `manifest.json`。

## 运行条件

需要能够读取 Skill、查看参考图片、调用内置 `image_gen`、读取生成文件并写入指定目录的 Agent 环境。只有文本能力或没有生图工具的环境无法执行完整流程；安装 Skill 不会自动获得这些权限。

Skill 不需要你在仓库中配置 API key，也不会自动切换付费 API。实际可用性、额度和费用由运行平台及账号决定，Skill 不承诺免费或固定额度。

## 安装

将本仓库下载到 Agent 支持的技能目录，保持以下结构：

```text
aigc-cloth-skill/
├── SKILL.md
├── README.md
└── references/
    └── fixed-prompt.md
```

如果你的 Codex 使用 `~/.codex/skills/` 作为本地技能目录，可以执行：

```bash
git clone https://github.com/dylanpindmc71/aigc-cloth-skill.git ~/.codex/skills/aigc-cloth-skill
```

若目标目录已存在，先检查已有版本，不要覆盖自己的修改。安装后让 Agent 重新发现技能；也可直接要求 Agent 读取本仓库的 `SKILL.md` 并按说明执行。宿主环境必须提供上述工具。

## 使用示例

### 单张照片

```text
使用 $aigc-cloth-skill，将这张照片中的服装生成一张服饰参考图。
保存到 /绝对路径/服装参考。
```

也可以直接上传图片；附件引用方式由当前工具能力决定。

### 批量照片文件夹

```text
使用 $aigc-cloth-skill，处理 /绝对路径/照片文件夹。
每套服装生成一张参考板，输出到 /绝对路径/服装参考。
排版不合格的按技能规则修正，并记录仍需复核的结果。
```

### 多角度照片合成一套

```text
使用 $aigc-cloth-skill，这三张照片是同一套衣服的不同角度。
综合可见细节，只生成一张参考板，保存到 /绝对路径/成品。
```

### 原文件夹内输出

```text
使用 $aigc-cloth-skill，处理 /绝对路径/照片。
在原文件夹内新建“服装参考”子文件夹保存成品，不覆盖原图。
```

建议每套服装放入独立子文件夹，降低自动分组歧义。若无法判断是否为同一套，Agent 会询问，同时继续其他明确的任务。

## 执行流程

1. 递归扫描输入图片，忽略隐藏文件、符号链接及已识别的输出目录。
2. 逐张看图，识别套装，将同套多角度照片合并为一组。
3. 完整使用[固定提示词](references/fixed-prompt.md)，追加本套说明与优先级约束。
4. 每套独立调用 `image_gen`，默认顺序处理。
5. 检查排版、服装一致性、人体残留、裁切和实际尺寸。
6. 保存成品，逐套更新清单；恢复任务时核验已有文件，只继续未完成项。

瞬时失败最多重试一次；质量不合格最多追加一次针对性修正。每套总计不超过三次调用，仍不合格则标记待复核，不无限生成。

## 输出与任务记录

未指定路径时，默认写入当前工作区的 `outputs/aigc-cloth/<时间戳>/`。指定目录需要可写权限；权限受阻时会明确报告。

```text
服装参考/
├── 001_套装名称_cloth-board.png
├── 002_套装名称_cloth-board.png
├── manifest.json
└── attempts/                 # 有重试时保留尝试产物
```

扩展名随实际格式确定。遇到同名文件增加版本后缀，不覆盖原图或已有成果。

`manifest.json` 记录来源、套装描述、推测区域、实际提示词、尝试次数、输出路径、实际尺寸、验收结果及失败原因。状态包括：

| 状态 | 含义 |
|---|---|
| `pending` | 等待处理 |
| `running` | 正在生成 |
| `completed` | 生成完成并通过检查 |
| `needs_review` | 仍有质量问题，需复核 |
| `failed` | 未能生成 |

## 模板与生成限制

固定模板原文保存在 `references/fixed-prompt.md`。模板包含人物摄影、皮肤、景深及铠甲等风格词，技能会追加约束消解冲突：无人体优先、所有视图清晰优先、没有铠甲的原服装不得添加铠甲。

- **模型版本：** Skill 调用的是工具，不锁定某个模型；不能据此保证使用 Image 2.5 或其他指定版本。以宿主平台实际提供的信息为准。
- **像素尺寸：** 模板中的“8K”是风格诉求，不是分辨率保证。验收读取文件实际尺寸，并检查宽 × 3 = 高 × 4。
- **背面与遮挡：** 没有照片的区域只能保守推测，会在交付中标明。要求零推测时，需补充参考照片。
- **真实度：** 生成图不是商品实拍、服装纸样或生产技术图，不能保证每处接缝、材质、背面和尺寸准确。
- **质量：** 自动检查和有限重试不能保证每次都符合标准；未通过的结果必须保留待复核状态。

## 功能边界

本技能负责“已有参考图 → 服装参考板”。给人物换装、网上采集商品、审美偏好学习、穿搭选品、实时价格和库存核验，都不是当前技能内置能力，需要另行完成。

商品图用于参考板时，生成效果可能美化或改变细节，不能用生成图替代对真实商品图的审美判断与购买核验。

## 隐私与素材

只向生图工具提供当前套装所需的参考图。参考图处理适用运行平台的数据政策；本技能不等于离线处理。请确保有权使用相关素材。

本仓库仅发布技能文本和说明，不包含私人照片、账号登录信息或生成记录。不要将自己的照片、`manifest.json` 或运行输出提交到公开仓库。
